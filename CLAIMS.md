# Evidence guide for the paper

Run `python3 reproduce.py` first. Each path under `build/` is generated by that command.

| Paper item | Reproduction path | Evidence |
|---|---|---|
| Table I: stratified sampling frame | `code/freeze.py` (called by `code/sensitivity.py`) | `data/negative_frame.csv`, `data/frozen_sample.csv`, `data/stratum_design.csv`; five byte-identical design outputs |
| Table II: published D6 detections; composition, no-diff, ten metrics, bootstrap | `build/legacy_audit.json`, `build/population_summary.json`, `build/two_domain_decomposition.csv` | Original CSV; 440 repositories, 4,400 repository–metric shifts, 12,000 resamples |
| Table III: account and record controls | `build/actor_ablation.csv`, `build/detector_summary.json` | 97 Rspack threads; per-PR match counts |
| Table IV: PR 13714 | `build/order_only.csv` | Four unchanged comment records; preserved ordering and changed ordering |
| 133 matches and 89 cross-comment links | `build/match_sources.csv`, `data/rspack_match_labels.csv` | Recomputed match signatures and comment IDs; recorded manual object/type classification |
| Eight order-only reversals | `build/order_only.csv` | Exact bodies, unchanged multiset of comment IDs and digests |
| Rspack 13478 and Valkey 2311 | `build/match_sources.csv`, `build/detector_summary.json`, `evidence/replay_threads.json` | Original source links, isolated and joined matching |
| Four Next.js HTML cases | `build/nextjs_replay.csv`, `reference/nextjs_mechanism_trace.csv` | Four original threads; isolated report, joined thread, one-space correction, boundary-limited HTML removal |
| 823 PR classifications, 185 Rspack qualifying bot comments, ESPHome counts | `build/evidence_audit.json`, `build/rspack_arm_census.csv` | PR outcomes linked to per-comment source ledger |
| Table V: estimated contrasts and simultaneous intervals | `build/domain_contrasts.csv`, `build/arm_estimates.csv`, `build/stratum_inference.csv` | Fixed census and probability sample; exact tail inversion |
| 439/440 leave-one-repository-out result | `build/leave_one_repository_out.csv` | All 440 exclusions under both definitions |
| Composition lower bounds | `build/two_domain_decomposition.csv` | Logical bounds conditional on observed labels |
| Shared-repository weighting | `build/repository_standardization.csv`, `build/legacy_audit.json` | Equal and combined-PR weights; original minimum-size thresholds |
| Three-definition and adverse-relabel sensitivity | `build/stress_summary.json` | Independent integer recurrence and count-space sensitivity |
| Other five channels in Rspack and Valkey | `build/channel_audit.json`, `evidence/channel_summary.csv`, `evidence/channel_records.csv`, `data/census_replay.csv` | 396 recorded channel summaries, 1,477 record digests, one coverage exception; optional body recovery with `code/fetch_sources.py --channels` |

The calculations and detector experiments execute automatically. Object/type classifications use recorded evaluator decisions. Source-linked inspection, body-hash checks, and the blank review worksheet support further review of those decisions. See [REVIEW.md](REVIEW.md).
